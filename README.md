# 贪吃蛇（无限生命版）

这是一个基于 HTML5 Canvas 的贪吃蛇小游戏。当前版本已改为“无限生命”：蛇不会因为撞墙或撞到自己而死亡；当越过边界时会从另一侧出现（环绕地图）。

## 玩法概述
- 控制：方向键或 W/A/S/D 改变方向
- 暂停/继续：空格键
- 移动端：页面下方提供方向按钮
- 计分规则：吃到食物 +10 分
- 最高分：自动保存在浏览器的本地存储中

- 方式一：直接在浏览器打开文件
